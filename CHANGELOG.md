# Changelog

All notable changes to Product Deconstructor are documented here.

## [2.2.0] - 2026-11-23

### Added
- Comprehensive product teardown methodology.
- User sentiment analysis covering likes, complaints, feature requests, and churn reasons.
- Funnel and conversion analysis, distinguishing measured evidence from hypotheses.
- Competitive benchmarking and product gap identification.
- Detailed technical architecture analysis covering services, APIs, databases, infrastructure, AI/ML, security, and reliability.
- Evidence classification: Verified, Inferred, Unknown, and Proposed.
- Source verification and quantitative evidence requirements.
- Structured DOCX report generation with tables, diagrams, and quality checks.

### Improved
- Category-specific analysis for marketplaces, SaaS, social platforms, e-commerce, fintech, AI products, and developer tools.
- Technical depth and architecture documentation requirements.
- Strategic recommendations and prioritised product opportunities.

### Status
Experimental. Execution testing and further refinement are still required.
